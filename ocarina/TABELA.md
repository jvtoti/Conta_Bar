# Ocarina — tabela de notas

Abra o `index.html` no navegador (Chrome, Edge ou Firefox) para tocar.

## Controles no PC

| Ação | Tecla |
|---|---|
| ● (Ré4) | Espaço |
| ▼ (Fá4) | Seta ↓ |
| ▶ (Lá4) | Seta → |
| ◀ (Si4) | Seta ← |
| ▲ (Ré5) | Seta ↑ |
| ♭ (meio-tom abaixo) | segurar Z |
| ♯ (meio-tom acima) | segurar X |
| Bend ↑ (até +2 semitons) | segurar W |
| Bend ↓ (até −2 semitons) | segurar S |
| Vibrato | segurar V |

## Nota → botão

| Nota | Botão | No teclado |
|---|---|---|
| Dó (C4) | ● + bend ↓ | Espaço + S |
| Dó♯ / Ré♭ | ● + ♭ | Z + Espaço |
| **Ré (D4)** | **●** | Espaço |
| Ré♯ / Mi♭ | ● + ♯ | X + Espaço |
| Mi (E4) | ▼ + ♭ | Z + ↓ |
| **Fá (F4)** | **▼** | ↓ |
| Fá♯ / Sol♭ | ▼ + ♯ | X + ↓ |
| Sol (G4) | ▼ + bend ↑ | ↓ + W |
| Sol♯ / Lá♭ | ▶ + ♭ | Z + → |
| **Lá (A4)** | **▶** | → |
| Lá♯ / Si♭ | ▶ + ♯ | X + → |
| **Si (B4)** | **◀** | ← |
| Dó (C5) | ◀ + ♯ | X + ← |
| Dó♯ / Ré♭ (C♯5) | ▲ + ♭ | Z + ↑ |
| **Ré (D5)** | **▲** | ↑ |
| Ré♯ / Mi♭ (D♯5) | ▲ + ♯ | X + ↑ |
| Mi (E5) | ▲ + bend ↑ | ↑ + W |

## Dicas

- O nome da nota aparece no topo da tela enquanto ela soa: use para conferir.
- Segure ♭/♯ (Z/X) **antes** de apertar a nota.
- Se a música passar do alcance (Dó4 a Mi5), toque tudo uma oitava acima ou abaixo.
